# Licence policy default and obligations

Use the company's own licence policy when one exists. Without one, this conservative default applies until the owner confirms or changes it.

## Default policy
- Approved for bundling and adaptation: Apache-2.0, MIT, BSD-2-Clause, BSD-3-Clause, ISC, MPL-2.0 (modified MPL files stay open), CC0, Unlicense, CC-BY-4.0 (with attribution).
- Excluded: GPL, AGPL, LGPL (copyleft would bind the bundle); CC-BY-NC and CC-BY-ND; any repository with no licence; custom licences with non-commercial terms.
- Anything else: the owner and counsel decide.

## Obligations by licence
| Licence | Keep | Also |
|---|---|---|
| Apache-2.0 | full licence text; NOTICE file text verbatim if present | state in modified files that they were changed; no use of the licensor's trademarks |
| MIT | copyright line and permission notice | credit in the adapted file |
| BSD-2/3 | copyright, conditions and disclaimer | BSD-3: no endorsement using the author's name |
| ISC | copyright and permission notice | |
| MPL-2.0 | licence notice in covered files | modified MPL files stay under MPL and available |
| CC0, Unlicense | nothing required | credit anyway as good practice |
| CC-BY-4.0 | attribution (author, source, licence link) | indicate changes |

## Provenance entry fields
Repository URL, full commit sha, licence identifier, original path, copyright holder, what changed (including "made generic" if company facts were removed), the full licence text and any NOTICE text.

## Attribution line (last line of an adapted file)
Adapted from <repo> (<path>), <licence>. Modified: <short description>.

## Author notices
Some authors ask that their NOTICE or authorship marks are never removed. Keep them verbatim in the provenance file.
