# Anchor, placement and hub rules

## Placement

1. At least one new money link in the upper 40 percent of the body (by character offset after any front matter). Readers drop off as they scroll and crawlers meet early links first. A "related reading" block at the bottom is never the only fix.
2. 2 to 4 new money links per source page, at most one inline link per target per page. A page that matches only one target gets one link.
3. Edit minimally: wrap an existing phrase when it fits; otherwise add one sentence that is useful on its own. Never rewrite the paragraph.

## Anchors

- 3 to 7 descriptive words saying what the target does: "check your record in seconds", "compare plans for small teams". Never "click here", "this tool" or "learn more".
- Each target gets at least five distinct anchors across the site (or one per linking page when fewer than five pages link to it).
- No exact anchor more than three times sitewide; identical short anchors repeated everywhere look manipulative.
- Internal links stay followed; never add nofollow, which throws away the equity you are routing.

## Callouts

One callout per source page (two for pages over 2,500 words), placed right after the section that explains the problem and before the step-by-step fix: that is when the reader wants the shortcut. The callout must render a real link (not script-only navigation) so crawlers count it. Every number in it comes from the products note.

## Hubs and laterals

| Page type | Must link to |
|---|---|
| Comparison page | the comparison index, two sibling comparisons, pricing |
| Tool or feature page | its index, two or three related features, one explainer post |
| Use case page | pricing and the one or two features that persona uses |
| Blog post or guide | its hub or category page and one or two posts in the same cluster |
| Every page | breadcrumb markup matching the visible breadcrumb and URL path |

Every money page sits at click depth 3 or less from the home page. Create an index page for a section once it has two or more children.

## Verification checklist

- Footer and nav links excluded from all counts.
- Every planned target fetched this turn and returns the real page (no redirect chain, no 404).
- No anchor reused more than three times sitewide.
- Each source links only to targets its topic already covers.
- Before and after counts use the same method and the same set of pages.
