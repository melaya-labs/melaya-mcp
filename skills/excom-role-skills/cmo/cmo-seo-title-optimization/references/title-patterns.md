# Title patterns

## Formula

Primary query + modifier or benefit + brand (when it fits). Treat the results page as the brief: write the clearest title that matches the page and the intent, not one from vibes.

## Checklist per title

- Primary query near the front.
- Title, meta description, H1 and slug about the same topic.
- Matches the page type (pricing, docs, product, comparison, guide, how-to, definition, list).
- Important words visible before truncation: 40 to 55 characters is the target. If the team's SEO note sets shorter limits for some engines, use those.
- Description up to about 155 characters, the promise of the click in plain words.
- Unique across the site.
- Mirrors useful patterns from the results page (numbers, "best", "vs", year) only when the page delivers them.
- Never vague labels ("Home", "Products", "Solutions").
- No year in the title unless the query demands freshness, and never change a slug to match a number or year.
- No hype words, no exclamation marks, no em dashes, no invented numbers.

## Patterns by intent

| Intent | Pattern |
|---|---|
| Beginner guide | "Beginner's Guide to [Topic]" or "[Topic]: What It Is and How to Use It" |
| Pillar | "The Complete Guide to [Topic]" or "How to [X]: Basics, Tips and Resources" |
| Definition | "What Is [Term]?" |
| How-to | "How to [Task]" or "How to [Task] Without [Obstacle]" |
| List | "[Number] Best [Tools] for [Audience]" |
| Checklist | "[Topic] Checklist: [Number] Steps to [Outcome]" |
| Comparison | "[A] vs [B]: [Decision or Outcome]" |
| Problem | "How to Fix [Problem]" |
| Product | "[What it does] for [Who]" |
| Pricing | "[Product] Pricing" |

Pick one pattern per page; do not mix formats unless the results page clearly does.

## Common fixes

| Problem | Before | After |
|---|---|---|
| Too vague | Home | Scheduling Software for Small Clinics |
| Too bloated | The Ultimate Complete Guide to the Many Benefits of Shift Planning | 8 Shift Planning Benefits for Clinics |
| Wrong intent | Plans for Growing Teams | Acme Pricing |

## Measuring

Compare the same query and page rows over equal windows before and after (28 days each). A title that loses clicks at a stable position is reverted.
