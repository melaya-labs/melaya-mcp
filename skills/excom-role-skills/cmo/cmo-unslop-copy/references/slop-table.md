# Slop patterns and fixes

| # | Pattern | Fix |
|---|---|---|
| 1 | Em dashes and en dashes, and spaced hyphens used as dashes | Period, comma, colon or parentheses. Number ranges use a plain hyphen or "to". |
| 2 | "Not just X, but Y", "It's not X, it's Y" | Delete the negative frame and state Y with its reason. |
| 3 | AI vocabulary: delve, pivotal, tapestry, landscape, testament, underscore, foster, garner, interplay, intricate, crucial, vibrant, showcase, additionally, moreover, furthermore | The plain word, or nothing. |
| 4 | Abstract metaphor nouns: substrate, vector, nexus, paradigm, north star, flywheel, bedrock | Base, method, center, model, goal, loop, foundation. |
| 5 | Fancy "is" and "has": serves as, stands as, boasts, features, offers a | "is", "has" or an active verb. |
| 6 | Puffery: groundbreaking, revolutionary, game-changing, seamless, blazing-fast, world-class, cutting-edge, next-generation, robust | The number or mechanism. |
| 7 | Trailing "-ing" clauses: "...ensuring scalability" | Cut, or make the fact its own sentence. |
| 8 | Pompous verbs: utilize, leverage, facilitate, commence, "in order to", "due to the fact that" | use, help, start, to, because. |
| 9 | Passive voice that hides the actor | Name the actor: "the agent checks the result". |
| 10 | Adverbs instead of deltas: "significantly reduces", "easily integrates" | The delta ("cuts setup from a day to an hour") or a stronger verb. |
| 11 | Bullet labels restated by the sentence | The label adds information the sentence does not repeat. |
| 12 | Padded triplets with two real points | List two. |
| 13 | Synonym cycling for one thing | Pick one noun and repeat it. |
| 14 | False ranges: "from startups to enterprises" | Name the real items. |
| 15 | Colon splices and colon reveals ("The result? 3x faster.") | Two sentences, or state it directly. |
| 16 | Title Case and emoji headings | Sentence case, no decorative emoji. |
| 17 | Curly quotes in code or markup | Straight quotes. |
| 18 | Chatbot artifacts: "In this article", "Let's dive in", "I hope this helps", "In conclusion" | Delete. |
| 19 | Formulaic transitions: "Despite these challenges...", "While X has its pros and cons..." | State the trade-off. |
| 20 | Flat cadence: every sentence the same length | Split sentences over 30 words; alternate short and medium. |

## Social-specific tells

- One short sentence per line for a whole post. Write paragraphs; break where a person would pause.
- Engagement bait: "Agree?", "Thoughts?", "Let that sink in". End on the point or a real question.
- Manufactured vulnerability with no real story behind it.
- Emoji used as bullets.
- "We are thrilled to announce", "excited to share".

## Grounding rules

- Mechanism over feeling, a number over an adjective.
- No attribution to unnamed experts or reports.
- Counts written as floors that stay true ("over 500 integrations"), never an exact figure that only holds today.
- Never imply a planned feature already ships, never call an unconfirmed integration a partnership.
