# Partner stages and attribution rules

## Stages and exit criteria

| Stage | Exit criteria |
|---|---|
| Sourced | On the list with a verified contact and a reason to write |
| Contacted | First message sent, message id in the ledger |
| Call booked or held | A booking exists or the call is logged |
| Offer made | Tier stated in writing |
| Agreement out | Envelope sent for signature |
| Completed, not filed | Envelope completed, PDF not yet in the partner's folder |
| Signed | Signed agreement filed in the partner's folder under the agreements folder, confirmed by search |
| Active | Tracking link clicked and a first co-marketing action live |
| Producing | At least one referred signup (the team's active-affiliate definition, if it is the same) |
| Customer-producing | At least one referred paying customer |

Only "Signed" counts toward the partner goal.

## Sourced, influenced, co-sell

| Type | Rule | Pays commission |
|---|---|---|
| Sourced | The customer came through the partner's tracking link within the attribution window | Yes, per the programme terms |
| Influenced | The partner helped a deal that arrived another way | No, reported only; any payment is an owner decision |
| Co-sell | Both sides worked the deal under a written co-sell agreement | Per that agreement only |

## Checks

- Every number names its tool and date.
- Conversion rates show sample size; small samples are labelled as such.
- A customer is never counted in two partners' sourced totals; disputes go to the CFO.
- Excluded referrals per the programme terms (self-referrals, own accounts, existing customers) are removed before counting.
