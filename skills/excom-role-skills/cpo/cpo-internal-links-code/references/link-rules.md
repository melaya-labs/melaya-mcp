# Internal link rules

## Placement

- At least one new money link in the upper 40 percent of the body (by character offset), because readers drop off and crawlers weight early links. Code blocks count toward length, so put the link above a long sample.
- 2 to 4 new money links per source page; at most one inline link per target per page.
- A page that matches only one target gets one link. Never add an unrelated target to reach two.
- One callout block per source page may point at a target already linked inline: it is a conversion block, not a second equity link.

## Anchors

- 3 to 7 descriptive words that say what the target does ("compare plans for small teams", "connect your CRM in two minutes").
- Never "click here", "this tool", "learn more".
- Each target gets at least 5 distinct anchors across the site (or one per linking page when fewer link to it). No exact anchor reused more than 3 times sitewide.
- Wrap an existing phrase when it fits; otherwise add one sentence that is useful on its own. Never rewrite the paragraph.

## Equity

- Internal links stay dofollow. Never add nofollow to an internal link.
- Footer, nav, language switchers and layout links never count as contextual.

## Hubs and depth

- Comparison pages link the comparisons hub, two sibling comparisons and pricing.
- Use-case pages link pricing and the one or two features that persona uses.
- Blog posts link their hub and one or two posts in the same cluster.
- Every page has a visible breadcrumb matching its BreadcrumbList structured data.
- Create a hub page only once a section has two or more children; a one-item hub is a thin page.
- Every money page sits within three clicks of home.

## Verification

- Before and after counts come from the same graph method in the same session.
- Zero new 404s: every target is a published route in the served HTML.
