# Look preset: Light UI clean

> **Use when:** SaaS feature explainers, onboarding, tutorials; anything where small UI text must stay crisp. Combine with any tone; the brand kit's own tokens and fonts always override the preset's defaults.

```yaml
id: look-light-ui-clean
kind: look
grounds: "pale cool grey or white; alternate with one brand-colour full-bleed scene"
palette: "the product's own UI tokens; accent darkened until it passes contrast as text on light"
type: "the product's UI font, larger; display weight for reads"
surfaces: "soft light shadows, thin borders, real component radii"
motion: "FLIP morphs, cursor choreography, typing, gentle push-ins"
transitions: "clean slide, clock wipe, card-fall"
texture: "none, or the product's own background pattern"
avoid: "light-leak shaders (they grey the ground), high CRF encodes (small text smears)"
```
