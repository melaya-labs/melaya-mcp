# Style presets

Presets are data: one tone (pacing, voice, transitions, audio, share copy) and one look (grounds, palette approach, type, surfaces, motion, texture) per piece. Pick them in [../modules/storyboard.md](../modules/storyboard.md) and [../modules/design-system.md](../modules/design-system.md); the brand kit overrides any default. Each file holds a `yaml` block with the same keys, so a script can read it.

| Tone | Use when |
|---|---|
| [tone-playful](tone-playful.md) | most consumer and developer products with personality; when nothing else clearly fits |
| [tone-polished](tone-polished.md) | serious products, premium positioning, enterprise, investors and partners; whenever the user says clean or elegant |
| [tone-startup-parody](tone-startup-parody.md) | absurd or recursive concepts that land harder when played completely straight |
| [tone-chaotic](tone-chaotic.md) | hype reels, memes, single-number launches, logistics parodies, anything with urgency |
| [tone-deadpan](tone-deadpan.md) | products whose strongest asset is one quote or one quiet observation; when restraint makes it land harder |
| [tone-cinematic](tone-cinematic.md) | launch films, products with natural scale (nature, space, infrastructure), grand claims |
| [tone-feature-cards](tone-feature-cards.md) | feature teasers, changelogs, onboarding, B2B products that should look like a real product page |

| Look | Use when |
|---|---|
| [look-editorial-minimal](look-editorial-minimal.md) | premium, thoughtful, design-literate audiences; long reads; restraint |
| [look-dark-premium](look-dark-premium.md) | developer tools, AI products, security, finance; launch films |
| [look-light-ui-clean](look-light-ui-clean.md) | SaaS feature explainers, onboarding, tutorials; anything where small UI text must stay crisp |
| [look-bold-poster](look-bold-poster.md) | launch hype, social cuts, events, consumer apps with a loud brand |
| [look-blueprint](look-blueprint.md) | infrastructure, APIs, integrations, data flow, architecture stories |
| [look-warm-organic](look-warm-organic.md) | consumer wellbeing, food, community, education; human stories |

A new preset is one file with the same keys; tones are named for an energy, looks for a visual family, never for a brand.
