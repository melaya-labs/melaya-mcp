# Worked example: 15 s social clip (fictional brand "Mossgrove")

Mossgrove is a fictional invoice-chasing agent for small agencies: it drafts payment reminders, schedules them and waits for a human approval before anything is sent. Every name and number below is invented for the example.

## Brief (short)

- **Deliverables:** 15 s clip, 1080x1920 for Reels, TikTok and Shorts, plus a 1920x1080 rebuild for X and LinkedIn; share copy.
- **Rubric:** it chases unpaid invoices for you; for agency owners who hate awkward reminders; nothing sends without your yes; strongest line "Invoices chase themselves."; hook visual: an overdue invoice card; flow: overdue invoice, drafted reminder, approve, paid.
- **Tone / look:** tone-playful / look-dark-premium. Music on (124 BPM measured), no voiceover, so no caption band; on-screen reads only.

## Script

| Beat | Read | Hold |

## Storyboard (strong downbeats at about 1.9, 3.9, 5.8, 7.7, 9.7, 11.6, 13.5 s)

| t (s) | Visual | Read and sound |
|---|---|---|
| 0.0 | Full-bleed saturated ground; a recreated "overdue invoice" card is punched from the lens (z 520 to 0, 0.55 s `expo.out`), then drifts | music already playing |
| 0.4 | | read 1 mask-rises |
| 1.9 | shock ring from the card; focus pull blurs everything else | soft impact at 1.88 |
| 2.0-5.8 | push into the recreated app; three tool rows stream one per beat (lookup, draft, schedule); the agent's cursor types a reminder at 0.012 s per character | read 2 tracking-collapses on 3.9; 3 key ticks |
| 5.8 | **true morph:** the "send" row grows into an approval card (FLIP 0.45 s, lands on 5.8) | card slide at 5.78 |
| 7.7 | the user's arrow presses Approve; button fills; state swaps | click 7.68, bell 7.8; read 3 slams |
| 9.7 | whip centred on 9.7 (start 9.45, 0.5 s), strong content at both edges | |
| 9.7-13.0 | proof: a "Paid" badge pops on three invoices, one per beat; a counter computed from time runs to the (fictional) total | read 4 blur-resolves |
| 13.5 | lockup: vector mark hands off to the real logo under a 1.05 overshoot; URL types at 45 ms per character | bell 13.48 |
| 13.6-15.0 | settled; only the glow breathes on the bass | |

Five SFX in total. Vertical layout: the card and UI fill the middle third, reads in the top-centre of the safe box (y 220-700), nothing below y 1480 or right of x 960 in the lower half. The landscape version is rebuilt (UI on the right, reads on the left), with the same music slice and locks.
